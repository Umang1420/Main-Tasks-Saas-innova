# Tic Tac Toe

A simple web-based Tic Tac Toe game built with HTML, CSS, and JavaScript.

## How it works
- Open the project in a browser to start the game.
- Choose either "2 Players" or "Vs Computer" mode.
- Enter player names and click "Start Game".
- Players take turns clicking the grid to place their mark.
- The game checks for a winner or a draw and shows a result message.
- Scores are tracked across rounds, and you can restart or start a new game.

## Features
- Two game modes: 2-player and single-player vs computer
- Player name input before starting
- Score tracking for each player
- Visual turn highlighting and winning tile animation
- Winner and draw messages
- Clean, responsive layout
- Beat the computer if you can..

## Run locally
Open the index.html file in your browser to play.
